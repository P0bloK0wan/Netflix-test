# Web demo implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Deliver the approved Portuguese streaming demonstration.
**Architecture:** React UI over a static catalog and a versioned browser storage adapter. Domain types and filtering stay independent of React for future Android/API use.
**Tech Stack:** React, TypeScript, Vite, Vitest, Playwright.
**Spec:** docs/web-demo-design.md (approved by user).

## Global constraints
- Portuguese, responsive dark interface with red accents and keyboard accessibility.
- Demo profiles, demo media, no real credentials or Netflix services.
- Keep source APK and analysis binaries outside Git.
- Per-profile local lists and playback progress; storage failures fall back to memory.

## Review focus
- Corrupt/unknown-version storage → safe defaults (task 1 test).
- Accented or whitespace-only search → normalized matching/all titles (task 1 test).
- Profile switch → no list/progress leakage (tasks 1 and 2 tests).
- Media failure or invalid time → visible retry and valid saved progress (tasks 1 and 3 tests).
- Modal focus and mobile overflow → keyboard dismissal, focus restoration, viewport fit (task 3 browser checks).
