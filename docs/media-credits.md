# Créditos e origem das mídias

## Catálogo

Os dez primeiros títulos, suas sinopses, anos, durações e temporadas são fictícios e foram escritos para esta demonstração. As fotografias ilustram esses títulos; não são cartazes oficiais. O destaque e a fileira “Em alta nesta demonstração” são curadoria estática, não métricas de audiência.

`Sintel` e `Big Buck Bunny` são obras reais de animação aberta. O player informa o trailer efetivamente reproduzido, inclusive quando ele é aberto a partir de um título fictício.

## Fotografias

Fotografias adquiridas do Unsplash e armazenadas localmente. As URLs originais e os identificadores de cada fotografia constam em [media-sources.json](media-sources.json). São usadas sob a [licença Unsplash](https://unsplash.com/license), com recorte na exibição, filtros de cor e sobreposição de texto. Nenhuma foto é vendida isoladamente.

## Tipografia e interface

DM Sans e Manrope são fontes abertas disponibilizadas pelo Google Fonts sob SIL Open Font License. A interface tem fallback para fontes do sistema. Ícones são SVGs simples escritos para o projeto.

Netflix é marca de seu respectivo titular. Este projeto é uma demonstração independente sem afiliação. Não distribui código descompilado, logotipos extraídos, filmes da Netflix nem credenciais. A referência ao APK e os limites da análise estão em `analysis/README.md`.
